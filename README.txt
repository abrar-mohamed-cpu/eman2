# موقع دعوة الخطوبة

## تشغيل الموقع
1. فكّي ضغط ملف ZIP.
2. افتحي مجلد `engagement_invitation` في VS Code.
3. افتحي `index.html` في المتصفح، أو استخدمي إضافة Live Server.
4. لتعديل البيانات، افتحي `script.js` وعدّلي القيم داخل `CONFIG` فقط.

## أماكن التعديل بالتحديد
في أول ملف `script.js` ستجدي:

- `groomName`: اسم العريس.
- `brideName`: اسم العروسة.
- `eventDate`: تاريخ الحفلة بصيغة `YYYY-MM-DD`، مثال `2026-11-14`.
- `eventTime`: وقت الحفلة بصيغة 24 ساعة، مثال `20:00`.
- `eventTimeLabel`: الوقت الذي يظهر للضيوف، مثال `الساعة 8:00 مساءً`.
- `venueName`: اسم القاعة أو المكان.
- `venueAddress`: العنوان بالتفصيل.
- `mapUrl`: رابط Google Maps للمكان.
- `whatsappNumber`: رقم واتساب بصيغة دولية بدون علامة + إذا احتجتِ استخدامه لاحقًا.

## ملاحظات
- التاريخ الافتراضي تجريبي ويمكن تغييره من `eventDate`.
- رابط الخريطة الافتراضي عام؛ استبدليه برابط المكان الصحيح.
- الخطوط تُحمّل من Google Fonts، لذلك يلزم اتصال بالإنترنت لعرضها.
- زر المشاركة يعمل بشكل أفضل بعد رفع الموقع على رابط عام HTTPS.
- ملفات الموقع الأساسية: `index.html` و`style.css` و`script.js`.
